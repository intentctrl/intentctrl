# @intentctrl/types

Shared TypeScript type definitions for IntentCtrl — an embedded AI runtime for web applications.

## Installation

```bash
npm install @intentctrl/types
```

## What it provides

Type definitions used across the IntentCtrl ecosystem. These include the tool contract types for serializing tool definitions, request and response shapes for the chat API, session management types for persisting conversations, and markdown annotation types for page content extraction.
