## Components

### IntentCtrlProvider

The root provider component. Must wrap any component that uses IntentCtrl hooks.

<TypeTable
  type={{

    permissions: {

## Hooks

### useIntentCtrl

Returns the full chat interface. Throws if used outside `IntentCtrlProvider`.

<TypeTable
  type={{
    messages: {
      description: "Array of messages in the current conversation",
      type: "UIMessage[]",
    },
    sendMessage: {
      description: "Send a new user message. Bundles page content, tools, permissions, and data context automatically.",
      type: "(text: string) => Promise<void>",
    },
    status: {
      description: "Current state of the chat lifecycle",
      type: '"submitted" | "streaming" | "ready" | "error"',
    },
    stop: {
      description: "Abort an in-progress streaming response",
      type: "() => void",
    },
    error: {
      description: "Latest error message, if any",
      type: "string | undefined",
    },
    approveToolCall: {
      description: "Approve a pending tool call",
      type: "(toolCallId: string) => Promise<void>",
    },
    denyToolCall: {
      description: "Deny a pending tool call",
      type: "(toolCallId: string) => void",
    },
    switchSession: {
      description: "Switch to a different conversation session",
      type: "(sessionId: string) => Promise<void>",
    },
    newSession: {
      description: "Create a new conversation session",
      type: "() => Promise<void>",
    },
    refreshSessions: {
      description: "Refresh the session list from the backend",
      type: "() => Promise<void>",
    },
    session: {
      description: "Current session state — active session ID, session list, and initialisation status",
      type: "SessionState",
    },
  }}
/>

### useTool

Registers a custom tool for the AI to call. The tool is available while the component is mounted.

<TypeTable
  type={{
    id: {
      description: "Unique tool identifier sent to the AI",
      type: "string",
      required: true,
    },
    description: {
      description: "Tells the AI what the tool does and when to call it. Write this for the AI.",
      type: "string",
      required: true,
    },
    inputSchema: {
      description: "Zod schema defining the tool's expected input. Validated before execution.",
      type: "ZodType",
      required: true,
    },
    needsApproval: {
      description: "If `true`, execution pauses for user confirmation via `approveToolCall` / `denyToolCall`",
      type: "boolean",
      default: "false",
    },
    handler: {
      description: "The function that runs when the AI calls the tool. Receives validated input, returns a value sent back to the AI.",
      type: "(input) => Promise<unknown>",
      required: true,
    },
  }}
/>

### usePermissions

Reads and updates the current permission state reactively.

<TypeTable
  type={{
    permissions: {
      description: "Current permission state — controls which built-in tools are available",
      type: "RuntimePermissions",
    },
    setPermissions: {
      description: "Update permissions. Changes take effect on the next message.",
      type: "(p: RuntimePermissions) => void",
    },
  }}
/>

### useDataContext

Injects contextual data that is sent with every chat request. Data is cleaned up when the component unmounts.

<TypeTable
  type={{
    data: {
      description: "Key-value pairs injected into the runtime context. Keys are cleaned up on unmount.",
      type: "Record<string, unknown>",
      required: true,
    },
  }}
/>

## Types

### RuntimePermissions

Controls which built-in tools are available to the AI.

<TypeTable
  type={{
    navigate: {
      description: "Route navigation",
      type: "boolean",
    },
    click: {
      description: "Click interactive elements",
      type: "boolean",
    },
    type: {
      description: "Type into text fields",
      type: "boolean",
    },
    highlight: {
      description: "Flash a region to draw attention",
      type: "boolean",
    },
    scroll: {
      description: "Scroll an element into view",
      type: "boolean",
    },
    extract: {
      description: "Read a field's value or text",
      type: "boolean",
    },
  }}
/>

- `undefined` — allowed, approval may be required
- `true` — allowed, bypasses approval
- `false` — denied
